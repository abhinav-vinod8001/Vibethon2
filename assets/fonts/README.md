# Resume fonts

Generated resumes embed Noto Sans Malayalam, Tamil, Devanagari (Hindi), and Telugu, which also cover Latin text. Fonts are bundled so exports need no browser or font-service request. All are unmodified variable TrueType fonts under the SIL Open Font License, with individual license files in this directory.

Font source: https://github.com/google/fonts/blob/main/ofl/notosansmalayalam/NotoSansMalayalam%5Bwdth%2Cwght%5D.ttf

These fonts were downloaded 25 October 2026. Exports select fonts per complete grapheme, preserving Indic conjunct shaping and mixed-language answers. Symbols outside every bundled font are displayed as explicit `[U+CODEPOINT]` labels rather than disappearing. The existing fontkit 2.0.4 shaping patch remains required.
