# Resume font

Noto Sans Malayalam is embedded in generated resumes to render Malayalam and Latin text without a browser/font-service dependency. The unmodified variable TrueType font is bundled with its SIL Open Font License in OFL.txt.

Font source: https://github.com/google/fonts/blob/main/ofl/notosansmalayalam/NotoSansMalayalam%5Bwdth%2Cwght%5D.ttf
